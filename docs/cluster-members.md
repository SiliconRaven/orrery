# 群成员管理、隐身与交接包

语言：**中文** | [English](cluster-members.en.md)

## 添加、重绑与隐身

所有群员均以**原生模式（`mode: "native"`）**加入集群（接口省略 `mode` 时默认 `"native"`，传其他值将被拒绝，界面不再提供模式切换）：

- **新建与接入**：支持在支持的适配器（如 Codex）上显式指定 **`projectPath`** 新建原生会话；接入已有对话（`attach`）时由适配器只读存储提取原会话的 `cwd`。同一个原生对话可同时加入多个集群，改名与头像通过 `PATCH /api/members/:id` 保存。
- **头像说明**：仓库**不内置任何角色预设插画**，成员可随时上传自定义头像，未上传自定义头像时界面显示对应应用识别徽标与成员标记。
- **重绑会话（`POST /api/members/:id/session`）**：切换同 harness 下的另一个对话；若存在未明确结束的在途投递，须携带 `confirmStopped` 确认原对话已停手。
- **成员隐身（`POST /api/members/:id/hidden`）**：与单纯视图隐藏不同，**Hub 在调度与 MCP 层强制阻断隐身成员**：隐身期间不再接收新消息投递、一切 MCP 工具调用（含只读工具）均返回隐身提示并空操作、不接受新派工或 `@` 点名，且在群里仅对用户与启用中的协调员可见（原有历史记录和既有任务保留）。

## 成员交接包（`GET /api/members/:id/handover`）

用于长会话换人或接手时由页面只读生成结构化摘要，**完全取材自 Hub 已有记录**（不调用模型，不读取未读消息队列，也不读取外部应用文件）：

- **用户最近请求（`requests`）**：该集群最近最多 5 条用户发言摘要；
- **关联与最近任务（`tasks`）**：包含任务状态、角色、最新提交摘要（`summary`）、`commitSha` / `mergedCommitSha`、最新验收结论（`review`）及未解决的求助问题（`questions`）；其中 `branch` 与 `commands` 字段**固定为 `null`**（Hub 不记录代码分支变动与执行过的终端命令，需交接时在界面或摘要中人工补充）；
- **最近投递异常（`deliveries`）**：近期失败、离线或结果未知的投递记录与原消息节选。

## 成员卡片状态与活动边界

- **忙/闲光环（`busy` / `idle`）**：只反映 **Hub 对该成员的投递通道状态**（是否有在途队列或未收到回执/结束回报），**不能证明宿主应用里的模型实际是否空闲**；悬停离线成员可查看具体离线依据与故障提示。
- **活动观察（`GET /api/activity`）**：仅当前接入了采集源的 harness（目前为 DeepSeek Harness `dsh-orrery`）会上报最小工具/轮次活动事件；其余没有采集源的 harness 一律显示为 `unknown`（[活动观察](activity.md)）。
- **用量概览**：各成员卡片按所在 harness 只读支持范围显示经 orrery 轮次 token、会话累计 token 与订阅额度窗口（详见 [额度与用量](usage.md)）。
