# 官方内置插件（`src/plugins/`，`v0.10.0-beta.1`）

语言：**中文** | [English](plugins.en.md)

> **Beta 提示**：官方内置插件随 **`v0.10.0-beta.1`（Beta 测试版）** 提供，非正式稳定版，插件工具、事件与界面插槽合同仍可能调整。

orrery 核心调度层仅负责集群、成员、原生群聊投递和消息存储；任务管理、协调员与资料收藏以官方内置插件的形式位于 `src/plugins/`。

## 插件机制与前端插槽

- 官方插件在 Hub 启动时加载，向 Hub 注册 MCP 工具、事件规则、定时检查及 Web/Bridge 路由，并可向协作网页注册**官方网页插槽（Slots）**。
- 可在设置页插件面板启用或禁用插件（写入 `<ORRERY_HOME>/plugins.json`），也可通过启动环境变量 `ORRERY_DISABLED_PLUGINS`（逗号分隔插件 ID）禁用；设置页插件禁用通常需重启 Hub 生效。
- 第三方外部插件（[外部插件说明](external-plugins.md)）运行在独立子进程，不开放网页前端插槽或浏览器代码执行权限。

## 三个官方内置插件与依赖关系

1. **`tasks`（任务与 `ship`）**：
   - 提供任务建单、三档验收（成员独立验收 / 自查 / 用户验收）、依赖关系、标签库、关注、`#number` 引用、停滞检测、交接与 `ship` 合并流。
   - **可单独使用**：关闭 `coordinator` 时，`tasks` 插件的所有任务看板、提交、验收与 `ship` 能力**依然照常可用**。
2. **`coordinator`（协调员工作台）**：
   - **依赖 `tasks` 插件**：只有在启用 `tasks` 时 `coordinator` 才能运行；提供 8 项可控的协调员委托策略，以及空闲任务与额度耗尽提醒。
3. **`bookmarks`（群资料库）**：
   - 支持群员（`bookmark_message`、`list_bookmarks`）与用户按标签收藏群聊结论或代码片段，供跨轮次查阅。

## 禁用后的已知影响

- 若同时禁用 `tasks`（或所有官方插件），集群保留基础群聊、消息路由与文件收发；由于 `coordinator` 依赖 `tasks`，禁用 `tasks` 时协调员也会一并停用。
