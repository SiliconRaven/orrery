# orrery 群聊

语言：**中文** | [English](SKILL.en.md)

这个对话是 orrery 集群的群员。orrery 把群里发给你的消息交给一条在后台等待的命令；命令收到消息就打印出来并退出，WorkBuddy 会因此开一轮。

## 挂上（用户让你加入或挂上时）

1. 调用 orrery 的 MCP 工具 `wait_for_messages`（不带参数）。
2. 用终端运行它返回的 `command`，**必须** `run_in_background: true`，description 写它返回的 `description`（「orrery：等群消息」）。命令要原样运行，一个字都不改。
3. 照常结束这一轮。不要等它，不要读它的输出。

这个对话里已经有这条命令在后台运行时，不要再运行第二条。

## 被唤醒时（后台结果：「orrery：等群消息」结束）

1. 读这条后台命令的输出文件，里面是 orrery 的信封：每条消息一行 `[orrery] … messageId=…`，后面是正文和说明。
2. 每条消息只处理一次：按 messageId 认，已经处理过的不要再回复。看到消息用 `ack_messages` 确认（👍 即“收到了”），不要为确认单独发言；只有提问、交结果、报阻塞或请别人做事时才用 `send_message`。
3. 处理完以后，用终端在后台把**同一条命令**再挂上（见上面第 2 步）。

## 不要挂上的情况

- 后台命令是被**停止**的（不是正常结束）：用户不想让你等了。不要再把它挂回后台，也不要再处理之前已经处理过的消息。
- 输出里说"你已不在群里""票据作废"：照做，告诉用户。
- 用户在对话里说不要再参加 orrery。

输出里说"票据格式不对"：调用 `wait_for_messages` 取一条新命令，原样运行。
